# ev-charging

Code and data for a research programme on electric-vehicle charging stations
under uncertainty: scheduling, sizing and the statistics of simulation-based
optimisation.

Each paper lives in its own folder under `papers/` with the scripts, data and
instructions that reproduce it. Each paper is archived as a tagged release with
its own Zenodo DOI; cite that release, not the repository head, since later
papers may change shared code.

| Paper | Folder | Release |
|---|---|---|
| Scheduling Under a Booking System: Quantile Objectives for Electric-Vehicle Charging With Known Fleet and Unknown State of Charge | `papers/paperA/` | `paperA-v1.0` |
